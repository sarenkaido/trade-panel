# پنل آلارم قیمت

یک سایت شخصی برای آلارم قیمت ارز و سهام. آلارم‌هایت را در سایت می‌سازی و وقتی قیمت به هدف رسید، **پیامش در تلگرام** (و اختیاری ایمیل) می‌آید. روی Cloudflare Worker اجرا می‌شود و **رایگان است**.

## امکانات
- ثبت‌نام و ورود با ایمیل و رمز
- آلارم‌های Long / Short (یا بدون جهت) با چند هدف
- قیمت زنده، فیلتر و دسته‌بندی
- تب‌های سناریو، پوزیشن‌ها، استراتژی، ترید تسک و واچ‌لیست (متن + دسته‌بندی)
- **ماشین‌حساب پوزیشن:** از سرمایه، درصد ریسک، لوریج، ورود، حد ضرر و (اختیاری) حد سود و کارمزد، مارجین لازم، حجم پوزیشن، تعداد، ریسک، نسبت سود به ضرر و قیمت لیکویید تقریبی را حساب می‌کند و روی یک خط‌کش قیمتی نشان می‌دهد
- طراحی «کاغذ نمودار»: پس‌زمینه‌ی شطرنجی، خط‌کش قیمت روی هر آلارم، تم تیره و روشن
- فارسی و انگلیسی
- با پنل باز، تیک آلارم در چند ثانیه نشان داده می‌شود؛ بدون پنل، چک خودکار هر دقیقه (با کندل‌های ۱ دقیقه‌ای؛ اگر قیمت فقط با یک سایه به هدف بخورد هم آلارم می‌آید)

ساز و کار داخلی: [ARCHITECTURE.md](ARCHITECTURE.md)

## راه‌اندازی (قدم به قدم)

نیاز داری: یک حساب **Cloudflare** (رایگان) و یک **ربات تلگرام**. دو راه برای دیپلوی هست؛ **یکی** را انجام بده.

### راه ۱ — با داشبورد Cloudflare (ساده‌ترین، بدون نصب چیزی)

**الف) ساخت KV (جای ذخیره‌ی اطلاعات)**
1. وارد [dash.cloudflare.com](https://dash.cloudflare.com) شو.
2. منوی چپ: **Storage & Databases ← KV**.
3. **Create Instance** (یا Create namespace) را بزن، اسمش را `alerts` بگذار و بساز.

**ب) ساخت ورکر**
1. منوی چپ: **Workers & Pages ← Create ← Create Worker**.
2. اسمش را بنویس (مثلاً `alert`) و **Deploy** را بزن.
3. **Edit code** را بزن، همه‌ی کد داخل ادیتور را پاک کن.
4. فایل [`worker.js`](worker.js) را از همین ریپو باز کن، **Raw** را بزن، همه‌اش را کپی کن و در ادیتور بچسبان.
5. **Deploy** را بزن.

**پ) وصل کردن KV**
1. صفحه‌ی ورکر ← **Settings ← Bindings ← Add ← KV namespace**.
2. اسم متغیر دقیقاً: `ALERTS_KV` — و KV که ساختی (`alerts`) را انتخاب کن ← **Save**.

**ت) چک خودکار هر دقیقه**
1. **Settings ← Trigger Events** (یا **Triggers**) ← **Add ← Cron Trigger**.
2. بنویس: `* * * * *` ← **Save**.

تمام! آدرس ورکر (مثل `alert.xxxx.workers.dev`) سایت توست.

### راه ۲ — با wrangler (ترمینال)

Node.js نصب باشد. بعد:

<div dir="ltr">

```bash
git clone https://github.com/sarenkaido/trade-panel
cd trade-panel
npx wrangler login
npx wrangler kv namespace create ALERTS_KV
```

</div>

- `login` مرورگر را باز می‌کند؛ **Allow** را بزن.
- دستور آخر یک `id` چاپ می‌کند. آن را در فایل `wrangler.toml` جای `id` بگذار (و اگر خواستی `name` را به اسم دلخواهت عوض کن).

بعد دیپلوی:

<div dir="ltr">

```bash
npx wrangler deploy
```

</div>

کد، KV و Cron همه از `wrangler.toml` خوانده می‌شوند.

دفعه‌های بعد که کد عوض شد: `git pull` و دوباره `npx wrangler deploy`.

### (اختیاری) دیپلوی خودکار با GitHub
اگر ریپو را در حساب خودت داری، می‌توانی هر پوش را خودکار دیپلوی کنی:
1. در Cloudflare یک **API Token** با قالب **Edit Cloudflare Workers** بساز (My Profile ← API Tokens).
2. در GitHub: ریپو ← **Settings ← Secrets and variables ← Actions ← New repository secret** و این دو را بساز:
   - `CLOUDFLARE_API_TOKEN` = توکن
   - `CLOUDFLARE_ACCOUNT_ID` = شناسه‌ی حساب (در داشبورد Cloudflare، صفحه‌ی Workers، سمت راست)
   - `KV_NAMESPACE_ID` = شناسه‌ی KV (در داشبورد: Storage & Databases ← KV)
3. از این به بعد با هر تغییر `worker.js` در شاخه‌ی `main`، دیپلوی خودکار انجام می‌شود. نتیجه در تب **Actions** است. دیپلوی دستی: Actions ← **Deploy to Cloudflare** ← **Run workflow**.

## اولین استفاده

### ۱) ثبت‌نام
1. آدرس سایت را باز کن؛ صفحه‌ی ثبت‌نام می‌آید.
2. ایمیل و رمز (حداقل ۸ کاراکتر) را بزن.
3. بار اول یک فیلد **کلید API سرویس Resend** هم می‌آید. در [resend.com](https://resend.com) رایگان ثبت‌نام کن، یک API key بساز و آنجا بگذار. (بدون دامنه‌ی تاییدشده، کد فقط به ایمیلِ همان حساب Resend می‌رسد؛ پس با همان ایمیل ثبت‌نام کن.)
4. کد ۶ رقمی را از ایمیل (پوشه‌ی اسپم را هم ببین) وارد کن. حسابت ساخته می‌شود.

> **زود ثبت‌نام کن!** تا وقتی حساب ساخته نشده، هر کسی که آدرس را بداند می‌تواند ثبت‌نام کند. برای قفل کردن کامل، متغیر `OWNER_EMAIL` را با ایمیل خودت بگذار (Settings ← Variables).

رمزت را فراموش کردی؟ «رمز را فراموش کردم» را بزن؛ کد به ایمیل می‌آید.

### ۲) وصل کردن ربات تلگرام
1. در تلگرام با `@BotFather` یک ربات بساز و **توکن** را بردار.
2. در سایت: ⚙️ تنظیمات (سه تب دارد: «اعلان‌ها»، «لاگ»، «حساب») ← تب «اعلان‌ها» ← بخش «تلگرام» ← توکن را بچسبان ← «ثبت توکن».
3. «باز کردن ربات در تلگرام» را بزن و در تلگرام **Start** را بزن.
4. به سایت برگرد و «تشخیص چت» را بزن. پیام تایید می‌آید.
5. برای اطمینان «تست تلگرام و ایمیل» را بزن.

### ۳) ساخت آلارم
دکمه‌ی **＋ آلارم جدید** را بزن، کوین (مثل `BTC`) و هدف را بنویس و ذخیره کن. تمام!

## سرعت و ظرفیت (اختیاری، پیشنهادی): دیتابیس D1

پلن رایگان KV فقط **۱۰۰۰ نوشتن در روز** دارد. با دیتابیس D1 همین پروژه حدود **۱۰۰ هزار نوشتن در روز** (۱۰۰ برابر) دارد و نگران پر شدن سهمیه نمی‌مانی. **داده‌های فعلی خودکار از KV منتقل می‌شوند** و هیچ کاری لازم نیست؛ جدول هم خودش ساخته می‌شود.

**۱) ساخت دیتابیس (داشبورد):** Storage & Databases ← **D1 SQL Database** ← **Create** ← اسمش را `alert-db` بگذار ← Create. بعد روی دیتابیس کلیک کن و **Database ID** را کپی کن.

**۲) وصل کردن:**
- **با دیتابیس به GitHub:** یک Secret به اسم `D1_DATABASE_ID` با مقدار همان شناسه بساز و دیپلوی را دوباره اجرا کن.
- **با داشبورد:** ورکر ← Settings ← Bindings ← Add ← **D1 database** ← اسم متغیر دقیقاً `DB` ← دیتابیس `alert-db` ← Save.
- **با wrangler:** در `wrangler.toml` چهار خط `[[d1_databases]]` را از حالت کامنت دربیاور و شناسه را بگذار، بعد `npx wrangler deploy`.

اگر D1 را وصل نکنی، همه‌چیز مثل قبل با KV کار می‌کند.

**چطور بفهمم D1 وصل شده؟** در سایت، ⚙️ تنظیمات ← «لاگ»، وضعیت چک خودکار را نشان می‌دهد و آخرش `· D1` یا `· KV` است.

## سهام و کوین‌ها

- **کوین:** فقط نامش را بنویس (`BTC`، `ETH`، ...).
- **سهام:** فقط نماد را بنویس (`AMZN`، `TSLA`، `NVDA`، ...)؛ سایت خودش `USDT.P` را ته آن می‌گذارد (مثلاً `AMZNUSDT.P`) و قیمت را از بازار فیوچرز صرافی‌ها می‌گیرد. هر نمادی را هم که خودت با `.P` تمام کنی همین‌طور حساب می‌شود.
- در ⚙️ تنظیمات ← «لاگ»، اگر همه‌چیز درست باشد پیام سبز «✅ همه چیز سالم است» را می‌بینی؛ در غیر این صورت دلیل مشکل (مثلاً کوینی که قیمتش گرفته نمی‌شود) همان‌جا نوشته می‌شود.

## نصب روی گوشی یا کامپیوتر (مثل یک اپ)

سایت یک وب‌اپ است و می‌شود آن را نصب کرد:
- **اندروید (Chrome):** منوی ⋮ ← «Install app» یا «Add to Home screen».
- **آیفون (Safari):** دکمه‌ی Share ← «Add to Home Screen».
- **کامپیوتر (Chrome/Edge):** آیکون نصب در نوار آدرس.

بعد از نصب، بدون نوار مرورگر و تمام‌صفحه باز می‌شود؛ تب‌ها روی موبایل پایین صفحه‌اند و دکمه‌ی «برگشت» بین تب‌ها کار می‌کند. آخرین تبی که باز بود یادش می‌ماند.

## اگر مشکلی پیش آمد
| مشکل | راه حل |
|---|---|
| سایت ارور ۵۰۰ می‌دهد | داشبورد ← ورکر ← **Logs** را نگاه کن. اگر نوشته «limit exceeded»، سهمیه‌ی رایگان KV پر شده و ساعت ۰۰:۰۰ UTC ریست می‌شود |
| می‌گوید KV وصل نیست | مرحله‌ی «وصل کردن KV» را چک کن؛ اسم متغیر باید دقیقاً `ALERTS_KV` باشد |
| آلارم نمی‌آید | ⚙️ تنظیمات ← «لاگ» را ببین؛ Cron باید `* * * * *` باشد |
| پیام تلگرام نمی‌آید | تنظیمات ← «تست تلگرام»؛ مطمئن شو در ربات **Start** زده‌ای |
| هر پیام دو بار می‌آید | یک ورکر قدیمی هنوز Cron دارد؛ آن را غیرفعال کن |
| دیپلوی خودکار قرمز شد | در Actions روی خطا کلیک کن؛ معمولاً توکن غلط/منقضی است یا `CLOUDFLARE_ACCOUNT_ID` اشتباه است |

## نکات
- **رمز عوض کردن:** تنظیمات ← «حساب». با تغییر رمز، نشست‌های دیگر بسته می‌شوند.
- **امنیت:** توکن ربات و کلید Resend در KV ذخیره می‌شوند و به مرورگر برنمی‌گردند.
- **پاک کردن KV** یعنی پاک شدن حساب و آلارم‌ها.
- **سقف رایگان:** ۱۰۰۰ نوشتن KV در روز؛ کد فقط وقتی چیزی تغییر کند می‌نویسد.
- ۵ ورود ناموفق، IP را ۱۰ دقیقه قفل می‌کند.
