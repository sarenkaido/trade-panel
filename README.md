# پنل آلارم قیمت

یک سایت شخصی برای آلارم قیمت ارز و سهام. آلارم‌هایت را در سایت می‌سازی و وقتی قیمت به هدف رسید، **پیامش در تلگرام** (و اختیاری ایمیل) می‌آید. روی Cloudflare Worker اجرا می‌شود و **رایگان است**.

## امکانات
- ثبت‌نام و ورود با ایمیل و رمز
- آلارم‌های Long / Short (یا بدون جهت) با چند هدف
- قیمت زنده، فیلتر و دسته‌بندی
- تب‌های سناریو، پوزیشن‌ها، استراتژی، ترید تسک و واچ‌لیست (متن + دسته‌بندی)
- **ماشین‌حساب پوزیشن (ساده):** فقط شش عدد وارد می‌کنی: سرمایه، درصد ریسک، لوریج، قیمت ورود، حد ضرر و (اختیاری) حد سود. جهت لانگ/شورت خودکار از روی حد ضرر تشخیص داده می‌شود و دکمه‌های 1R و 2R و 3R حد سود را خودشان پر می‌کنند. نتیجه یک نمودار سود/ضرر مثل TradingView و مارجین لازم، حجم پوزیشن و تعداد است. کارمزد و نحوه‌ی محاسبه در بخش‌های جمع‌شده هستند و مقادیر حساب در مرورگر یادت می‌ماند.
- **تب دلخواه:** با دکمه‌ی «＋ تب جدید» تب خودتان را با نام و آیکون بسازید و هر چه خواستید داخلش بنویسید (ذخیره‌ی خودکار؛ تا ۱۰ تب؛ با ✎ ویرایش یا حذف می‌شود). تب‌های دلخواه جدا از تب‌های اصلی نشان داده می‌شوند و داخل هر کدام نوت‌ها مثل تب «سناریو» به شکل کارت هستند (عنوان اختیاری، جستجو، ✎ ویرایش، 🗑 حذف، دکمه‌ی «＋ نوت جدید»؛ تا ۳۰ نوت)
- طراحی «کاغذ نمودار»: پس‌زمینه‌ی شطرنجی، خط‌کش قیمت روی هر آلارم، تم تیره و روشن
- فارسی و انگلیسی
- با پنل باز، تیک آلارم در چند ثانیه نشان داده می‌شود؛ بدون پنل، چک خودکار هر دقیقه (با کندل‌های ۱ دقیقه‌ای؛ اگر قیمت فقط با یک سایه به هدف بخورد هم آلارم می‌آید)

ساز و کار داخلی: [ARCHITECTURE.md](ARCHITECTURE.md)

## انتخاب محل استفاده و راه‌اندازی

**اول تصمیم بگیر پنل را کجا می‌خواهی استفاده کنی.** لازم نیست هر دو نسخه را نصب کنی؛ هر مسیر مستقل است و فقط همان زیرساختی را راه‌اندازی می‌کنی که لازم داری.

<details>
<summary><strong>گزینه ۱ — فقط نسخه وب روی Cloudflare Worker</strong> (مناسب استفاده با مرورگر)</summary>

در این حالت پنل به شکل یک سایت مستقل باز می‌شود؛ با آدرس اختصاصی Worker در مرورگر کامپیوتر یا گوشی. نیازی به Telegram Mini App یا سرویس TGCLOUD نداری.

**نیازمندی‌ها**
- حساب Cloudflare
- یک KV Namespace برای ذخیره اطلاعات
- GitHub repository از همین پروژه

**مراحل راه‌اندازی**
1. در Cloudflare از بخش **Storage & Databases → KV** یک Namespace بساز و شناسه (ID) آن را بردار.
2. در Cloudflare از **My Profile → API Tokens** یک API Token با دسترسی ویرایش Workers بساز.
3. در GitHub مخزن پروژه‌ات را باز کن و به **Settings → Secrets and variables → Actions** برو. این مقادیر را اضافه کن:
   - Secret با نام **CLOUDFLARE_API_TOKEN**
   - Secret با نام **CLOUDFLARE_ACCOUNT_ID**
   - Secret با نام **KV_NAMESPACE_ID**
   - (اختیاری) Secret با نام **D1_DATABASE_ID**، اگر دیتابیس D1 ساخته‌ای.
4. به تب **Actions → Deploy Trade Panel → Run workflow** برو.
5. در قسمت مقصد، **فقط نسخه وب — Cloudflare Worker** را انتخاب کن و workflow را اجرا کن.
6. بعد از موفقیت، آدرس Worker را در خروجی Cloudflare یا بخش Workers داشبورد ببین و باز کن.

**بعد از نصب:** ثبت‌نام و ورود با ایمیل و رمز از داخل سایت انجام می‌شود. اگر می‌خواهی اعلان‌ها را در تلگرام دریافت کنی، در تنظیمات خود پنل یک ربات بساز/وصل کن؛ این فقط برای ارسال اعلان است و پنل همچنان وب‌سایت باقی می‌ماند.

</details>

<details>
<summary><strong>گزینه ۲ — نسخه Telegram Mini App</strong> (مناسب استفاده مستقیم داخل تلگرام)</summary>

در این حالت کاربر پنل را از داخل ربات تلگرام باز می‌کند؛ ورود با حساب تلگرام انجام می‌شود. این مسیر علاوه بر خود Mini App به سرویس TGCLOUD و یک Worker زمان‌بندی‌شده در Cloudflare برای بررسی آلارم‌ها نیاز دارد.

**نیازمندی‌ها**
- حساب تلگرام و ربات ساخته‌شده با [@BotFather](https://t.me/BotFather)
- حساب Cloudflare
- حساب/پروژه TGCLOUD و توکن دسترسی آن
- GitHub repository از همین پروژه

**مراحل راه‌اندازی**
1. در تلگرام به [@BotFather](https://t.me/BotFather) برو، یک ربات بساز و Bot Token را نگه دار.
2. پروژه Telegram Serverless را در TGCLOUD بساز/انتخاب کن و توکن دسترسی پروژه را بردار.
3. در Cloudflare یک API Token با دسترسی ویرایش Workers بساز و Account ID را بردار.
4. در GitHub به **Settings → Secrets and variables → Actions** برو و این مقادیر را اضافه کن:
   - Secret با نام **TGCLOUD_TOKEN**
   - Secret با نام **CLOUDFLARE_API_TOKEN**
   - Secret با نام **TELEGRAM_BOT_TOKEN** (توکن ربات BotFather)
   - Secret یا Variable با نام **CLOUDFLARE_ACCOUNT_ID**
5. به **Actions → Deploy Trade Panel → Run workflow** برو.
6. مقصد **نسخه تلگرام — Telegram Mini App** را انتخاب و workflow را اجرا کن. این انتخاب، Mini App را build و منتشر می‌کند، schema دیتابیس TGCLOUD را اعمال می‌کند و Worker بررسی دوره‌ای آلارم‌ها را روی Cloudflare منتشر می‌کند.
7. پس از موفقیت انتشار، در تلگرام رباتت را باز کن و **Start** را بزن؛ دکمه‌ی باز کردن پنل، Mini App را اجرا می‌کند.

**توجه:** برای این مسیر، Cloudflare Worker نسخه وب (گزینه ۱) دیپلوی نمی‌شود. Cloudflare فقط میزبان زمان‌بندی بررسی آلارم‌هاست؛ رابط کاربری داخل تلگرام اجرا می‌شود.

</details>

### انتخاب مقصد در هر بار انتشار

هر زمان خواستی نسخه جدیدی منتشر کنی، دوباره از **GitHub → Actions → Deploy Trade Panel → Run workflow** مقصد دلخواهت را انتخاب کن. گزینه‌ها روشن و مستقل‌اند:

- **فقط نسخه وب — Cloudflare Worker:** فقط سایت روی Worker منتشر می‌شود.
- **نسخه تلگرام — Telegram Mini App:** فقط Mini App و Worker زمان‌بندی مخصوص آن منتشر می‌شوند.

با push کردن کد، هیچ‌کدام از مقصدها خودکار منتشر نمی‌شوند؛ بنابراین انتخاب نهایی همیشه دست خودت است. هر دو نسخه می‌توانند جداگانه فعال باشند، اما برای استفاده فقط یکی را لازم داری.

## سرعت و ظرفیت (اختیاری، پیشنهادی): دیتابیس D1

پلن رایگان KV فقط **۱۰۰۰ نوشتن در روز** دارد. با دیتابیس D1 همین پروژه حدود **۱۰۰ هزار نوشتن در روز** (۱۰۰ برابر) دارد و نگران پر شدن سهمیه نمی‌مانی. **داده‌های فعلی خودکار از KV منتقل می‌شوند** و هیچ کاری لازم نیست؛ جدول هم خودش ساخته می‌شود.

**۱) ساخت دیتابیس (داشبورد):** Storage & Databases ← **D1 SQL Database** ← **Create** ← اسمش را `alert-db` بگذار ← Create. بعد روی دیتابیس کلیک کن و **Database ID** را کپی کن.

**۲) وصل کردن:**
- **با دیتابیس به GitHub:** یک Secret به اسم `D1_DATABASE_ID` با مقدار همان شناسه بساز و دیپلوی را دوباره اجرا کن.
- **با داشبورد:** ورکر ← Settings ← Bindings ← Add ← **D1 database** ← اسم متغیر دقیقاً `DB` ← دیتابیس `alert-db` ← Save.
- **با wrangler:** در `wrangler.toml` چهار خط `[[d1_databases]]` را از حالت کامنت دربیاور و شناسه را بگذار، بعد `npx wrangler deploy`.

اگر D1 را وصل نکنی، همه‌چیز مثل قبل با KV کار می‌کند.

**چطور بفهمم D1 وصل شده؟** در سایت، ⚙️ تنظیمات ← «لاگ»، وضعیت چک خودکار را نشان می‌دهد و آخرش `· D1` یا `· KV` است.

## سهام و کوین‌ها

- **کوین:** فقط نامش را بنویس (`BTC`، `ETH`، ...).
- **سهام:** فقط نماد را بنویس (`AMZN`، `TSLA`، `NVDA`، ...)؛ سایت خودش `USDT.P` را ته آن می‌گذارد (مثلاً `AMZNUSDT.P`) و قیمت را از بازار فیوچرز صرافی‌ها می‌گیرد. هر نمادی را هم که خودت با `.P` تمام کنی همین‌طور حساب می‌شود.
- در ⚙️ تنظیمات ← «لاگ»، اگر همه‌چیز درست باشد پیام سبز «✅ همه چیز سالم است» را می‌بینی؛ در غیر این صورت دلیل مشکل (مثلاً کوینی که قیمتش گرفته نمی‌شود) همان‌جا نوشته می‌شود.

## نصب روی گوشی یا کامپیوتر (مثل یک اپ)

سایت یک وب‌اپ است و می‌شود آن را نصب کرد:
- **اندروید (Chrome):** منوی ⋮ ← «Install app» یا «Add to Home screen».
- **آیفون (Safari):** دکمه‌ی Share ← «Add to Home Screen».
- **کامپیوتر (Chrome/Edge):** آیکون نصب در نوار آدرس.

بعد از نصب، بدون نوار مرورگر و تمام‌صفحه باز می‌شود؛ تب‌ها روی موبایل پایین صفحه‌اند و دکمه‌ی «برگشت» بین تب‌ها کار می‌کند. آخرین تبی که باز بود یادش می‌ماند.

## اگر مشکلی پیش آمد
| مشکل | راه حل |
|---|---|
| سایت ارور ۵۰۰ می‌دهد | داشبورد ← ورکر ← **Logs** را نگاه کن. اگر نوشته «limit exceeded»، سهمیه‌ی رایگان KV پر شده و ساعت ۰۰:۰۰ UTC ریست می‌شود |
| می‌گوید KV وصل نیست | مرحله‌ی «وصل کردن KV» را چک کن؛ اسم متغیر باید دقیقاً `ALERTS_KV` باشد |
| آلارم نمی‌آید | ⚙️ تنظیمات ← «لاگ» را باز کن: آنجا قیمت الان و فاصله‌ی هر آلارم تا هدفش و نتیجه‌ی آخرین پیام تلگرام (ارسال شد / چرا نشد) نوشته شده. اگر پیام ارسال نشود، آلارم از دست نمی‌رود و دوباره تلاش می‌شود. همچنین Cron باید `* * * * *` باشد |
| پیام تلگرام نمی‌آید | تنظیمات ← «تست تلگرام»؛ مطمئن شو در ربات **Start** زده‌ای |
| هر پیام دو بار می‌آید | یک ورکر قدیمی هنوز Cron دارد؛ آن را غیرفعال کن |
| دیپلوی خودکار قرمز شد | در Actions روی خطا کلیک کن؛ معمولاً توکن غلط/منقضی است یا `CLOUDFLARE_ACCOUNT_ID` اشتباه است |

## نکات
- **رمز عوض کردن:** تنظیمات ← «حساب». با تغییر رمز، نشست‌های دیگر بسته می‌شوند.
- **امنیت:** توکن ربات و کلید Resend در KV ذخیره می‌شوند و به مرورگر برنمی‌گردند.
- **پاک کردن KV** یعنی پاک شدن حساب و آلارم‌ها.
- **سقف رایگان:** ۱۰۰۰ نوشتن KV در روز؛ کد فقط وقتی چیزی تغییر کند می‌نویسد.
- ۵ ورود ناموفق، IP را ۱۰ دقیقه قفل می‌کند.

- فایل بکاپ بین نسخه وب و Mini App قابل جابه‌جایی است.
